# GitOps Iceberg Data Platform

Config-driven data platform on Google Cloud. The previous NYC-taxi platform
(Spark jobs, dbt, Looker, Composer, Argo CD) is preserved on branch `v1`.

## Layout

```
config/
  defaults.yaml          shared defaults (flags, ...)
  profiles/demo.yaml     per-environment profile (project_id, region)
  load.py                deep-merges defaults + profile
  resolved.yaml          GENERATED by `make resolve` -- do not edit
infra/environments/demo  Terraform root; reads config/resolved.yaml via yamldecode
```

## Usage

```bash
make resolve                     # PROFILE=demo by default
make tf-validate
cd infra/environments/demo
terraform init
terraform apply -auto-approve
```

Terraform state lives in `gs://gitops-iceberg-data-platform-tfstate` (prefix `terraform/demo`).
